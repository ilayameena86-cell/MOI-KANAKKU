மொய் கணக்கு – Android app project

APK பெறும் வழி (GitHub மூலம், இலவசம்):
1. github.com-இல் புதிய repository உருவாக்கவும் (Public அல்லது Private).
2. இந்த folder-இல் உள்ள அனைத்து கோப்புகளையும் (.github folder உட்பட) repository-இல் upload செய்யவும்.
3. Repository-இல் "Actions" tab-ஐத் திறக்கவும். "APK உருவாக்கு" தானாக ஓடும் (சுமார் 5-8 நிமிடம்).
4. முடிந்ததும் அந்த run-ஐத் திறந்து, கீழே "Artifacts" பகுதியில் moi-kanakku-apk என்பதைப் பதிவிறக்கவும்.
5. Zip-ஐத் திறந்தால் app-debug.apk கிடைக்கும். Phone-இல் நிறுவவும் ("Unknown sources" அனுமதி தேவைப்படும்).
